# Nagi 需求文档

## 目标

- 做一个能语音对话的交互式数字人：用户对着麦克风说话，系统完成语音识别、LLM 回复、语音合成，Unity 中的 3D 角色带着表情和动作开口回答
- 通过逐版本迭代，完整走一遍客户端、后端、数据库、Web 后台、图形、工程化和 AI 的开发流程
- 最终产出：可运行的 Windows 程序、每版本的开发日志、技术博客和演示视频

## 功能清单

- **v0.1**：语音 → 文本 → LLM → 语音的最小闭环，Unity 角色播放回复
- **v0.2**：MySQL 存用户、人设、对话记录，Redis 存上下文，Vue 后台管理人设和查看对话
- **v0.3**：情绪驱动的表情和动作，粒子特效、后处理、Shader，鼠标和键盘交互
- **v0.4**：自动化测试、统一接口格式、日志、Docker 部署、GitHub Actions、代码重构
- **v0.5**：本地 Whisper 和本地 LLM，云端/本地可切换，情绪分类小模型，图片输入，向量库长期记忆
- **v1.0**：微服务拆分、消息队列、网关、JWT 鉴权和限流、音频流式传输、性能优化、打包发布

## 不做什么

- 不训练大语言模型或语音模型，只调用现成的 API 或开源模型（仅训练小型情绪分类模型）
- 不做手机端和网页端数字人，只做 Windows 的 Unity 客户端
- 不做大规模并发，目标是单用户体验流畅
- 不做商业化功能，如支付、多语言界面
- 美术支线（自建模型）放在最后，不影响主线进度
